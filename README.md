# 海航 PLUS · 官方航线地图

海南航空2666 PLUS会员¥199经济舱权益的航线与时刻筛选工具。地图与城市、省份、航司、时间及班期筛选联动，支持缩放、平移、机场点击和航班详情。航线与时刻仅依赖官方数据，不采集库存。

## 当前覆盖范围

**尚未取得最新全国全量。请勿将此项目描述为2026全国全部适用航线。**

- **2026官方已查询计划**：2026-10-09杭州出发2666计划，以及杭州→北京首都全部时段对照。合并28条记录、17方向。默认显示适用时段25条；选择“全部已收录时段”可看到白天3班对照。其他出发城市及日期尚未查询。
- **2025官方全国历史表**：海航官网参考表全部1692条记录、11航司、983单向机场对。表页更新至2025-10-29，适用日期标注“即日起—12月25日”。历史参考，不能判断2026航班。具体日期筛选禁用，支持时段与星期筛选。
- 两个来源分开选择与统计。每条记录可查看官方原文链接和原始备注。未收录不代表没有航班。
- 199元税费另付；以官方规则及实际购票内容为准。本项目与海南航空无隶属关系。

## 本地运行和构建

需要Node.js22.12+。

```sh
npm ci
npm run dev
npm run build
```

`dist/index.html`是自包含静态HTML，可离线打开。提交到main后GitHub Actions自动构建并部署Pages。

## 官方数据更新

`src/assets/flights.json`保存标准化官方记录；`data/official/`保存可复核原始文本；`scripts/import-official.py`负责转换。增加官方当前计划时必须保存查询城市、类型、日期及来源，更新界面覆盖说明，并进行时间边界与历史数据隔离验证。不要用第三方班表补全。

完整范围、官方查询限制、转换规则、地图辅助来源及许可见[DATA_SOURCES.md](DATA_SOURCES.md)。原创代码MIT；官方内容、底图和依赖遵循各自条款。
